# Curriculum Notes

## Apprentice Track
**Focus:** High-frequency NEC topics, timed lookup drills, measurable speed improvement

**Core Objectives:**
- Master the Codeology 4-step lookup method (Classify → Keywords → Article → Verify)
- Build speed on common exam topics: working space, GFCI requirements, conductor sizing, overcurrent protection
- Develop pattern recognition for NEC chapter organization
- Measure progress through timed drills (target: <2 minutes per lookup)

**Key Topics:**
- Chapter 1: General requirements (definitions, working space, installation standards)
- Chapter 2: Wiring and protection (conductors, overcurrent, grounding basics)
- Chapter 3: Wiring methods (conduit, cable types, raceways)
- Chapter 4: Use equipment (motors, transformers, lighting, receptacles)

**Success Metrics:**
- Lookup time: Start at 5+ minutes → Target under 2 minutes
- Accuracy: Correct article/section identification
- Confidence: Can explain the Codeology reasoning for each lookup

**Recommended Mode:** Guided Method (book mode) for learning, Index Search (fast mode) for practice

---

## Journeyman/Master Track
**Focus:** Field troubleshooting, complex system design, compliance verification, specialized calculations

**Core Objectives:**
- Rapid field reference for calculations (voltage drop, ampacity, conduit fill)
- Complex system design (service sizing, feeder calculations, motor circuits)
- NFPA 70E compliance (arc flash, PPE, safe work practices)
- PLC/L5X integration for industrial automation projects

**Key Topics:**
- Service and feeder calculations (Article 220, 215, 230)
- Motor circuits (Article 430)
- Grounding and bonding systems (Article 250)
- Hazardous locations (Articles 500-516)
- NFPA 70E arc flash boundaries
- PLC ladder logic interpretation (L5X parsing)
- Conduit bending and field calculations

**Success Metrics:**
- Field calculation speed (voltage drop, ampacity)
- System design accuracy (service sizing, protection coordination)
- Compliance verification (arc flash studies, grounding systems)
- PLC program comprehension (can read and modify ladder logic)

**Recommended Modes:**
- Quick Answer (quick mode) for NEC citations
- Ugly's Reference (uglys mode) for calculations
- PLC Parser (/plc) for L5X files

## Integration with Co-Pilot Modes

**Apprentice Workflow:**
1. Start with Guided Method to learn the process
2. Practice with Index Search to build speed
3. Use Quick Answer to verify understanding
4. Never use Ugly's Reference (that's for field calculations, not exam prep)

**Journeyman/Master Workflow:**
1. Use Quick Answer for fast NEC citations in the field
2. Use Ugly's Reference for voltage drop, ampacity, conduit calculations
3. Use PLC Parser for L5X file analysis
4. Use Guided Method only when teaching apprentices

## Measurement Framework

**Apprentice Metrics:**
- Time to lookup (start → answer)
- Correct article/section identification rate
- Codeology explanation quality (can they teach it back?)
- Exam pass rate on practice tests

**Journeyman/Master Metrics:**
- Field calculation accuracy
- System design correctness
- Compliance verification speed
- PLC program comprehension rate

**Data Collection:**
- Co-Pilot logs mode usage patterns
- Track which questions get asked most frequently
- Identify knowledge gaps by mode/topic
- Build question banks for practice tests
