# Product Positioning — Code Compass

## Core Message
Speed, precision, validation — NOT memorization.

## Teaching Angle
- The Co-Pilot trains apprentices on rapid "hunting" protocols
- User searches, locates the article/table, verifies in the book
- AI is a COACH and VALIDATION LAYER — not a replacement for the codebook
- Never frame the product as "you don't need the book anymore"

## What We Build
- Fast lookup tools (Guided Method, Index Search, Quick Answer, Ugly's Reference)
- Field utility features (PLC parsing, compliance workflows)
- Measurable outcomes (time saved, errors caught, exam pass rates)

## What We Do NOT Build
- Generic study app features
- Memorization tools (flashcards, rote drilling)
- Anything that positions AI as a substitute for the NEC codebook

## Curriculum Tracks

### Apprentice Track
- Focus: State journeyman exam speed
- 15-second keyword drill: complex question → identify keyword → identify article → verify offline
- Metric: "How fast can you find the answer in the book?"

### Journeyman / Master Track
- Focus: Field troubleshooting, PLC logic, NFPA 70E, compliance lookup
- Tools: L5X parser, data center compliance, Ugly's Reference mode
- Metric: Hours saved per project, errors caught before field commissioning

## Business / Investor Angle
- Lead with traction and metrics, not narrative
- Focus on: ARR, growth rate, CAC payback period, gross margin
- AI investor matching tools = supplement only, not primary channel
- Push grants and workforce programs: WIOA, SBA E2G (qualify through training org partners)
- Investor language: "We're building the Bloomberg Terminal for electrical compliance" — not "a study app"

## Language Guardrails
| SAY THIS | NOT THIS |
|----------|----------|
| Fast lookup | Study tool |
| Hunting protocol | Memorization |
| Coach and validation layer | AI replaces the book |
| Field utility | Exam prep app |
| Measurable outcomes | Learn the NEC |
| 15-second drill | Flashcards |
| Locate and verify | Memorize and recall |
